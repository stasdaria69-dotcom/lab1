1. Входные данные
Возраст человека — возраст
Цена билета — цена
2. Результат
Стоимость билета:
до 7 лет — 0
от 7 до 17 лет — половина цены
с 18 лет — полная цена
3. Алгоритм словами
Ввести возраст человека и цену билета.
Проверить: возраст < 7?
Да → билет бесплатный, стоимость = 0.
Нет → перейти к следующей проверке.
Проверить: возраст < 18?
Да → стоимость = цена / 2.
Нет → стоимость = цена.
Вывести стоимость билета.
Конец.
4. Используемые структуры
Используется разветвляющаяся структура (если → то → иначе), потому что результат зависит от возраста.
5. Блок-схема для draw.io
Последовательность фигур должна быть такой:
Овал:Начало
Параллелограмм:Ввести возраст, цену
Ромб:Возраст < 7?
↙ Да ↘ Нет
Прямоугольник:Итоговая цена = 0
Ромб:Возраст < 18?
 ↙ Да ↘ Нет
6. Проверка на двух наборах данных
Набор 1:
Возраст = 5 лет, цена = 400 ₽
→ возраст < 7 → билет бесплатный → 0 ₽
Набор 2:
Возраст = 12 лет, цена = 400 ₽
→ возраст не меньше 7, но меньше 18 → 400 / 2 = 200 ₽
Можно дополнительно проверить третий вариант:
Набор 3:
Возраст = 20 лет, цена = 400 ₽
→ возраст ≥ 18 → 400 ₽
